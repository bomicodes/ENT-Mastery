ENT Mastery v12.1 — Production Visual Repair + Anatomy Safety

Priority 1: interpretation assets
- Ships all 48 v11.8 interpretation SVGs and all 8 v11.9 allergy SVGs in the patch itself.
- Adds an onerror fallback to Interpretation Atlas images so a missing asset cannot render as an unexplained broken-image icon.
- Keeps the visuals explicitly labeled as generated teaching schematics rather than patient imaging.

Anatomy Atlas
- Stops using the crude generated anatomy SVGs as live teaching images.
- Classical public-domain source plates are shown only for topics conservatively judged to match the depicted anatomy.
- Mismatched or modern surgical topics are intentionally text-first until a suitable source exists.
- Modern approach topics show a source-needed panel rather than a misleading anatomy picture.
- Adds four Sleep Surgery anatomy modules: palate/lateral pharyngeal wall, tongue base/hyoid, hypoglossal nerve/HNS, and MMA skeletal relationships.

This release prioritizes not misleading the learner: no image is preferable to the wrong image.
