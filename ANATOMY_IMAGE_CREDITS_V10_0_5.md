# ENT Mastery v10.0.5 — Anatomy Image Credits

All anatomy images in this pass are sourced from Wikimedia Commons files whose
individual file pages identify them as public-domain or Creative Commons material.

The site displays a visible source/credit beneath every image and links back to the
corresponding Commons file page.

Image families used:
- Gray's Anatomy plates: public domain.
- Sobotta 1909 plate / Sobotta-derived external carotid illustration: public domain.
- Auditory Pathway by Jonathan E. Peelle: CC BY 4.0.

The images are used as anatomical reference plates only. ENT Mastery does not copy
figures from the user's copyrighted contemporary textbooks or commercial atlases.
