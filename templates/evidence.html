One source layer for the whole curriculum.

Current public guidelines and regulatory sources calibrate management-changing recommendations. Core texts support durable anatomy, physiology and operative mental models. Visual atlases are used for pattern recognition where permitted.

How sources are used

Current guideline / regulatory source → thresholds, candidacy, treatment sequencing and surveillance that can change.

Core textbook / operative reference → anatomy, physiology, pathology framework and durable surgical principles.

Visual atlas → recognition and interpretation. Older treatment recommendations are not assumed to be current.
